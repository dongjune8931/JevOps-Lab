# JevOps-Lab

Jev를 DevOps 업무에 적용하고 실제 효과와 한계를 검증하는 프로젝트·실험 저장소입니다.

각 작업은 독립된 폴더, 문서, Codex 세션, PR을 사용합니다. 저장소 구조와 작업 규칙은 [`docs/WORKING_AGREEMENT.md`](docs/WORKING_AGREEMENT.md)에서 확인할 수 있습니다.
